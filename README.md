# 기고 수금내역서 자동 생성 대시보드

## 사용 방법
1. 이 폴더 전체를 GitHub Pages 저장소에 업로드합니다.
2. `index.html`, `app.js`, `template.xlsx`는 같은 폴더에 둡니다.
3. 페이지에서 DCM 수금내역서와 SAP매출 `.xlsx` 파일을 각각 선택합니다.
4. `업로드 파일 검증 · 계산`을 눌러 미리보기를 확인합니다.
5. `수금내역서 생성`을 눌러 결과 엑셀을 다운로드합니다.

## 적용 규칙
- 메리놀병원 DW24 / 부산성모병원 DW24 / 주식회사기고(GIGO) DW21·DW22: DCM 합계(N)
- 그 외 DW21·DW22·DW28: SAP
- 그 외 채널: DCM 전월(L)
- SAP 제품명에 콩코르 또는 크레스토 포함: 현금 / 나머지: 어음
- SAP 간납가: AW + AZ
- 약국현금 / 병원현금 / 도입현금 / 도입어음 각각 다음 백만원 단위로 올림, 차액은 최대 수금대상 한 건에 반영

## 주의
- 브라우저에서 ExcelJS를 CDN으로 불러옵니다. 인터넷 연결이 필요합니다.
- 업로드한 엑셀 파일의 데이터는 서버로 전송하지 않고 브라우저 내부에서 처리됩니다.
