# 기고 수금내역서 자동 생성 대시보드

DCM 수금내역서와 SAP매출 파일 2개를 업로드하면 브라우저에서 수금대상을 계산하고 결과 엑셀을 생성합니다.

## 적용 규칙
- 메리놀병원 DW24 / 부산성모병원 DW24 / 주식회사기고(GIGO) DW21·DW22: DCM 합계
- 그 외 DW21·DW22·DW28: SAP
- 그 외 채널: DCM 전월
- SAP 제품명에 콩코르 또는 크레스토 포함: 현금
- SAP 그 외 제품: 어음
- SAP 금액: AW + AZ 간납가
- 약국현금 / 병원현금 / 도입현금 / 도입어음별 합계를 다음 백만원 단위로 올림
- 올림 차액은 각 구분에서 수금대상이 가장 큰 한 건에 반영

## 사용 방법
1. DCM 수금내역서 .xlsx 업로드
2. SAP매출 .xlsx 업로드
3. 업로드 파일 검증 · 계산
4. 미리보기 및 미매칭 확인
5. 수금내역서 생성

업로드한 파일은 외부 서버로 전송하지 않고 사용자의 브라우저 내부에서 처리합니다.
